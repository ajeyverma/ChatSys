# Contributing to ChatSys

Thank you for your interest in ChatSys! We welcome contributions to improve our fault-tolerant LAN communication system.

## How to Contribute

### Reporting Bugs
If you find a bug, please create a new issue with a clear description, steps to reproduce, and any relevant logs.

### Feature Requests
Have an idea for a new feature? We'd love to hear it. Please open an issue to discuss it first.

### Pull Requests
1. Fork the repository.
2. Create a new branch for your feature or bugfix.
3. Keep your changes focused and concise.
4. Ensure your code follows the project's style and architecture patterns.
5. Submit a pull request with a detailed description of your changes.

## Development Workflow

1.  **Install Dependencies**: `npm install`
2.  **Run Locally**: `npm start`
3.  **Build**: Use the appropriate build script for your OS (e.g., `npm run build:x64`).

### Code Style
- Use clear, descriptive variable and function names.
- Comment complex logic when necessary.
- Maintain consistent indentation (2 or 4 spaces as per the project's standard).

## Communication
Join our discussions in the issues page or reach out to the project maintainers.

## Code of Conduct
Please review our [Code of Conduct](./CODE_OF_CONDUCT.md) before contributing.
